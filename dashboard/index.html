    About this feed

    This page reads a public channel using ThingSpeak's read-only feeds API. Browser notifications require permission and only work while this page is open. For private channels, a read API key must be entered and should not be embedded in a public page.

    The sensor node evaluates the alert tier and publishes it as field6. Any listed condition triggers its tier; the strongest matching tier wins. As written, light above 50% is a Tier 3 Critical condition.

    To share this dashboard, host this static page and use its URL with ?channel=YOUR_CHANNEL_ID. Anyone with the link can view a public channel.

    Light is displayed as a normalized ADC percentage, not calibrated lux. ThingSpeak free channels allow one update every 15 seconds.
